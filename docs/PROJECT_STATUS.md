# Status do projeto

## Estado atual

A arquitetura e o produto demo estão funcionais. O projeto está preparado para receber os dados oficiais sem precisar reconstruir frontend, API, persistência ou estrutura de testes.

## Pronto e utilizável agora

- backend FastAPI;
- dashboard web;
- workspace React;
- banco local e PostgreSQL;
- persistência de previsões e cenários;
- geração de dados sintéticos;
- pipeline de ML demo;
- explicabilidade demo;
- otimização de cenário;
- auditoria inicial de CSV;
- adaptador inicial de nomes ONS;
- testes automatizados;
- Docker;
- CI;
- documentação de equipe.

## É demonstração, não resultado da competição

- probabilidades atuais;
- métricas dos modelos atuais;
- padrões encontrados nos dados demo;
- energia em risco mostrada no dashboard;
- fatores explicativos atuais;
- valores econômicos e emissões;
- disponibilidade de bateria/carga flexível.

## Depende dos dados oficiais

- target definitivo;
- horizonte definitivo de previsão;
- universo de usinas;
- features finais;
- tratamento de dados faltantes oficial;
- modelo vencedor;
- threshold operacional;
- métricas finais;
- viabilidade das estratégias de mitigação;
- estimativas de impacto.

## Critério para considerar o projeto pronto para apresentação

1. Dataset oficial auditado.
2. Dicionário de dados revisado pelo time.
3. Leakage review concluído.
4. Baseline documentado.
5. Modelo final validado temporalmente.
6. Métricas congeladas em um Model Card.
7. Otimização com premissas defensáveis.
8. Dashboard usando somente outputs oficiais/derivados válidos.
9. Demo reproduzível em outro computador.
10. Pitch ensaiado com contingência offline.
